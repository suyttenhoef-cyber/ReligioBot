# Bases légales — à obtenir

Dossier destiné à recevoir le texte intégral (Moniteur belge / Wallex, pas un résumé) des 12
sources légales/circulaires listées dans `CLAUDE.md` (section "Volet 2"). Vide à ce stade.

Une fois un texte obtenu, l'extraire vers `corpus_par_matiere/corpus_reglementation_fabriques.json`
(le document correspondant y est déjà déclaré avec ses métadonnées) en suivant le schéma décrit
dans `README.md` à la racine du dépôt — un texte à la fois, jamais plusieurs en parallèle.
